# АРМАДА — учёт перевозок

## Сделано
1. ЕТО + создание/закрытие заказа  
2. Заправка при закрытии (сумма только админу)  
3. Нулевой / с грузом / до стоянки — только админу  
4. Роли + PIN админа `2580`  
5. Гибрид: админ назначает / водитель создаёт сам  
6. Админ-таблица и финансы  
7. Закрытие смены: одометр на стоянке → авто «до стоянки»

## Веб (общая база на сервере)
Открыть в браузере с любого компьютера/телефона:

**http://aptown1.fvds.ru/**

- PIN администратора: `2580`
- Данные общие: сохраняются на сервере (PocketBase), не пропадают при смене браузера
- Админка БД: http://aptown1.fvds.ru/_/
- Редирект со старой ссылки: https://laser-erp.github.io/armada-web/
- Исходники веб-версии: `web-preview/` → деплой в `/var/www/armada` на VPS
