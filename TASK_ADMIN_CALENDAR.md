## Задача

Календарь в **админке → Заявки** (не водитель): выбор **дня** или **периода**, чтобы не листать длинный список закрытых дней. Админку водителя не трогать.

## Эталон (уже сделано у водителя)

Водитель: вкладка **История**, PR #99, сборка `2026-08-09-driver-hist-cal`.  
Логика: `driverHistCal`, `driverHistSelectDay`, `driverHistCalHtml` в `web-preview/index.html`.  
Скопировать **идею и UX**, не слепо код — у админа другая структура данных.

## Где в админке

- Экран **Заявки** (`renderAdmin`, фильтры «Все / Назначен / …»)
- **Не** вкладки ЕТО и Биржа (там календарь не нужен)
- Над карточками дней (`adminGroupCardHtml` / `buildAdminShiftDayGroups`)
- Группы уже по **дню смены + водитель + авто** — фильтровать их по `dayKey`

## Логика календаря (как у водителя)

- **1 тап** по дню → только этот день
- **2-й тап** по **другому** дню → период между ними (включительно)
- **Сбросить** → снять фильтр по датам
- Дни с заказами/сменами — точка на ячейке
- Стрелки ‹ › — смена месяца
- Подпись периода: «09.08.2026» или «05.08.2026 — 09.08.2026» / «Все дни»

## Фильтры (важно для админа)

У админа много фирм/машин — календарь **не заменяет** фильтры:

1. **Супер:** уже есть `adminOwnerFilter` (фирма/админ) — календарь работает **поверх** него
2. **Обычный админ:** только своя зона (`canAdminSeeOrder`) — как сейчас
3. **Опционально v1** (если просто): одна строка «Водитель» / «Госномер» (select) — только по уже видимым заказам; если сложно — отложить, только календарь + owner filter

## Поведение списка

- **Без выбора даты:** показывать группы **как сейчас** (или только текущий месяц — если длинный список, лучше по умолчанию **текущий месяц**, «Сбросить» = все в зоне фильтра)
- **С выбором:** только группы, у которых `dayKey` попадает в период
- Сводка сверху (Заказы / Выручка / ЗП) — **по отфильтрованным** группам
- Раскрытие карточек дня — как сейчас (`adminExpandedGroups`)
