## Цель

В **админке → Заявки** добавить фильтры **Водитель** и **Госномер**, чтобы сузить список групп после выбора дня/периода в календаре.

## Где

- Экран **Заявки** (`renderAdmin`), рядом с календарём (`adminOrdersCalHtml` / `#admin-orders-cal`)
- **Не** трогать: ЕТО, Биржу, админку водителя, цвета статусов, вкладки водителя

## Эталон (уже есть)

Календарь дат: `ensureAdminOrdersCal`, `adminOrdersFilterGroups`, `adminOrdersCalHtml`, `adminOrdersSelectDay`  
в `web-preview/index.html`. Группы: `buildAdminShiftDayGroups` → у группы есть `driverName`, `vehiclePlate`, `dayKey`.

## Логика (строго)

1. Два `<select>`: **Водитель**, **Госномер**.
2. Опции строить из **видимых админу групп** (`allGroups` до фильтра по датам, или из тех же заказов, что уже видит админ) — уникальные `driverName` / `vehiclePlate`, плюс пункт **«Все»**.
3. Порядок фильтров: **даты календаря → водитель → госномер**.  
   Функцию фильтрации можно расширить: например `adminOrdersFilterGroups(groups, cal)` + фильтр по `state.adminOrdersCal.driver` / `.plate` (или соседние поля в `state`).
4. Сводка «Заказы / Выручка / ЗП» и список карточек/таблицы — только по уже отфильтрованным группам.
5. Кнопка календаря **«Сбросить»** — сбрасывает **только даты** (как сейчас: `from`/`to`/`showAll`).  
   Селекты водитель/номер **не** сбрасывать этой кнопкой; либо отдельная маленькая кнопка «Сбросить фильтры» / сброс селектов в «Все» — на выбор, минимально.
6. Пустой результат: текст вроде «Нет заявок за выбранные дни» (можно уточнить: «Нет заявок по фильтру»).
7. UI: просто, без карточек-украшений; стили в духе существующего `.drv-cal` / админ-фильтров.
