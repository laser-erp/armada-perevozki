# Конкурентный контекст и S3 ETRN MVP (2026)

Ориентир для этапа S3: два спринта кода + пилот с оператором.

## Позиция АРМАДА

| Конкурент / альтернатива | Для кого | Слабость для микро-парка |
|--------------------------|----------|---------------------------|
| Excel + WhatsApp | 1–5 ТС | потери заявок, нет биржи |
| ATI | биржа грузов | не TMS, не учёт смен |
| Cargo.run и аналоги | средний парк | дорого и сложно для 1–15 ТС |
| АРМАДА | 1–15 ТС | пакет: заказы, водитель, биржа кабинетов, ЭТрН в тарифе |
