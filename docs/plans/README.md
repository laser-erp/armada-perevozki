## Порядок работ (рекомендация, не жёсткий)

1. **DOCUMENTS** — конструктор + Бух.доки (вы уже согласовали логику).
2. **ADMIN** — довести документы в карточке заявки до бланка.
3. **CUSTOMER** — акт, пакет документов, позже ЭДО.
4. **PLATFORM** — юридические + публикация на сайт.
5. **DRIVER** — ЭТрН с реальным оператором (после ключей).

Между этапами — **не смешивать** роли в одном PR без необходимости.
