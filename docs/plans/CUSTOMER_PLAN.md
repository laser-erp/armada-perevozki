# План: заказчик (портал)

> **Кто:** внешний клиент перевозчика (не перевозчик на бирже).  
> **Вход:** https://app.armada.sx/z/ или `/z/{slug}/`  
> **Связано:** [ADMIN_PLAN.md](./ADMIN_PLAN.md) · [DOCUMENTS_PLAN.md](./DOCUMENTS_PLAN.md)

---

## 1. Зона ответственности

- подать **заявку** на перевозку;
- смотреть **статус** своих заявок;
- скачать **счёт**, **документы по заявке**;
- подписать **рамочный договор** (галочка, MVP);
- **не** админка, **не** биржа между перевозчиками.

> Перевозчик, выступающий **заказчиком на бирже**, работает из **админки**, не из `/z/`.

## 3. Статус функций

### 3.1. Вход и доступ

| Функция | Статус | Примечание |
|---------|--------|------------|
| Портал `/z/` | ✅ | |
| Свой URL `/z/{slug}/` на фирму | ✅ | slug в «Тарифы» / space |
| Телефон + PIN из карточки заказчика | ✅ | админ создаёт в справочнике |
| Самостоятельная регистрация | ⬜ | не планировалось в MVP |
| Оферта / политика ссылка | 🟡 | `index.html`, `legal.html` |

### 3.2. Заявка

| Функция | Статус | Примечание |
|---------|--------|------------|
| Маршрут, груз, тип кузова | ✅ | |

| Чат-форма заявки | ✅ | |
| Расчёт км и цены (ориентир) | ✅ | |

### 3.3. После отправки

| Функция | Статус | Примечание |
|---------|--------|------------|
| Список заявок + статусы | ✅ | |
| Push при смене статуса | ✅ | |
| **Счёт** с QR СБП | ✅ | `customer-invoice.js` |
| **Рамочный договор** | 🟡 | галочка «Согласен», не ЭДО |

| **ЭТрН T1** (грузоотправитель) | 🟡 | sandbox, отдельная ссылка |

### 3.4. Документы — когда что видно

| Документ | Когда появляется |
|----------|------------------|
| Счёт | После заявки (если сумма есть) |
| Рамочный договор | При первой работе |
| Заявка, договор‑заявка | После назначения водителя и ТС |
| ЭТрН | Когда оформлена |
| **Акт** | **После закрытия заявки** |
