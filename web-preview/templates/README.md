# Шаблоны документов АРМАДА

Печатные формы генерируются в `order-documents.js`:

- **framework-contract** — рамочный договор заказчик ↔ перевозчик
- **application** — заявка на перевозку (ТС, водитель, маршрут)
- **transportApp** — договор‑заявка на рейс
- **act** — акт выполненных работ

Тексты на русском с плейсхолдерами реквизитов из карточки компании. Для юридической доработки правьте функции `buildFrameworkContractBody` и `buildOrderDocBody` в `order-documents.js`.

ЭТрН: структура данных в `etrn.js`, полная интеграция — оператор ЭПД (СБИС, Контур, Диадoc).
