# Подключение канала MAX — пошагово

**Где настроить в приложении:** супер-админ → **Соцсети** → блок **MAX**.  
**API на сервере:** уже включён (`POST /armada-api/marketing/max/test`).

---

## Шаг 1. Канал в мессенджере MAX

1. Создайте **канал** (бизнес-профиль / «Каналы в MAX для бизнеса» — см. [dev.max.ru/docs/channels/create](https://dev.max.ru/docs/channels/create)).  
2. Запомните **название** и ссылку — их можно дать в постах TG/VK.

---

## Шаг 2. Бот и токен

1. Откройте [MAX для разработчиков](https://dev.max.ru) → **Чат-боты** → создайте бота (или используйте существующего).  
2. Скопируйте **токен** (⋮ → Настройки → копировать).  
3. **Не** публикуйте токен в чатах и git.

---

## Шаг 3. Бот — администратор канала

1. В MAX откройте **ваш канал** → администраторы → **добавьте бота** с правом публиковать посты.  
2. Без этого API вернёт ошибку доступа.

---

## Шаг 4. Узнать chat_id канала

Варианты (любой один):

**A.** Документация MAX: раздел «Получение chat_id» в [dev.max.ru/docs-api](https://dev.max.ru/docs-api) — через `POST /subscriptions` или события после добавления бота в канал.

**B.** После добавления бота напишите **тестовое сообщение** в канал вручную; в кабинете разработчика посмотрите **updates** / webhook — в payload будет `chat_id`.

**C.** Поддержка MAX / ваш интегратор — запросить id канала для Bot API.

`chat_id` — **число** (integer), сохраните без пробелов.

---

## Шаг 5. Ввести в АРМАДА

1. Войдите **супер-админ** → https://staging.app.armada.sx/a/ или https://app.armada.sx/a/  
2. Меню → **Соцсети** → **MAX**.  
3. Вставьте **токен** и **chat_id** → **Сохранить MAX**.  
4. Нажмите **«Тестовый пост в канал»** — в канале должно появиться сообщение с ссылкой на app.

Если ошибка:

| Текст | Что сделать |
|-------|-------------|
| `marketingMax не настроен` | Нажмите «Сохранить MAX» ещё раз |
| `token и chat_id обязательны` | Заполните оба поля |
| `401` | Токен неверный или отозван |
| `403` / access | Бот не админ канала |

---

## Шаг 6. Отложенные посты (позже)

В данных `marketingMax.queue` — очередь постов со статусом `scheduled` и временем `scheduledAt`.  
Кнопка **«Опубликовать due-посты»** или `POST /marketing/max/tick` публикует всё, у чего время наступило (если включена галочка **Автопубликация**).

Раздел «Маркетинг» в UI для очереди — см. [MARKETING_RAZDEL_APP.md](./MARKETING_RAZDEL_APP.md).

---

## Безопасность

- Токен хранится в **облачном state** (PocketBase), видит только супер-админ в форме.  
- Не дублируйте токен в `store.js` и на GitHub.
